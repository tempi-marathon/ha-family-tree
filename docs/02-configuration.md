# 2. Configuration

## Gazetteer countries (integration)

Open the integration → **Configure** (options flow).

Select ISO country codes to download from GeoNames (e.g. `NL`, `BE`, `DE`).
Downloads happen once; search is fully offline afterward. Public GeoNames data
only — no personal data is sent.

## Family surname shortcuts (panel)

In the Family Tree panel → **Settings**, edit **Family surname shortcuts**.
These appear as quick filters on the dashboard and people list. Matching uses
surname with or without Dutch prefixes (`van`, `de`, …).

## User ↔ person link

In the panel **Settings**, link each HA user to a person. That drives the
ancestor/descendant indicator in the people list.
